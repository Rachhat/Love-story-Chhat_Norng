# A6 Clean Flip Book

This version removes the top title/header, the Open book button, and the Scroll A6 pages button.

## Use
Open `index.html`. Click the right side of the book to turn forward, the left side to go back. You can also use the Previous/Next buttons, mouse wheel, swipe, or keyboard arrows.

All pages are embedded directly inside `index.html`, so no assets folder is needed.
